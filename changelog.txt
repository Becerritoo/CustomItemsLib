V1.4.0 (2026-10-15)
* Add a public API for signed, non-monetary item data used by consumer plugins.
* Expose textured player heads without attaching reward metadata for signed consumer templates.
* Replace the abandoned Spiget updater with a shared Hangar release client.
* Select only public, reviewed stable releases compatible with the exact Paper version.
* Verify update downloads by filename, size and SHA-256 before staging them for restart.
* Preserve the active plugin filename when placing updates in Bukkit's update directory.
* Treat projects that have not yet been published on Hangar as having no available update.

V1.3.0 (2026-10-15)
* Add an optional PhysicalCurrencyService contract through Bukkit's ServicesManager.
* Delegate consumer-specific balance accounting and Shopkeepers slot policy to the active currency plugin.
* Remove CustomItemsLib build dependencies and class references to BagOfGold and MobHunting.
* Keep the legacy Citizens adapter without registering the BagOfGold banker trait.
* Own PlaceholderAPI message processing and updater runtime inside CustomItemsLib.
* Read the shared player ID by column name so consumer statistics can be stored for new players.
* Verify standalone, BagOfGold, MobHunting and combined startup on Paper 1.21.11.
* Stop probing consumer plugins during the CustomItemsLib startup path.
* Run historical consumer-file imports once and record their outcome without removing source files.
* Finish startup without Vault, Reserve or a physical-currency consumer and keep library commands available.
* Retire legacy presentation adapters and keep CMILib as the maintained action-bar and boss-bar backend.

V1.2.0 (2026-10-06)
* Begin semantic versioning for the fork maintained by Becerritoo.
* Validate the release on Paper 1.21.11.
* Separate CMILib action-bar and boss-bar support from the optional CMI hologram integration.
* Add independent configuration switches for CMI and CMILib.
* Fail cleanly when database initialization is incomplete and make shutdown null-safe.
* Preserve and repair the reserved RandomBounty database identity safely.
* Expand MySQL account names to VARCHAR(64) when an older schema is detected.
* Include maintained fixes for reward tokens, hidden lore, ProtocolLib, Vault providers,
  missing player records, reward pickup and modern Paper version detection.
