# CustomItemsLib 1.2.0

CustomItemsLib 1.2.0 is the first semantic release of the fork maintained by
[Becerritoo](https://github.com/Becerritoo). Rocologo remains credited as the original author.

## Highlights

- Validated on Paper 1.21.11.
- Separates CMILib visual messages from the optional CMI hologram integration.
- Adds independent configuration switches for CMI and CMILib.
- Handles incomplete database initialization and shutdown safely.
- Preserves the reserved RandomBounty database identity using transactional statements.
- Expands existing MySQL `mh_PlayerSettings.NAME` columns to `VARCHAR(64)` when needed.
- Includes maintained fixes for signed reward tokens, hidden lore, ProtocolLib, Vault provider
  changes, missing player records, reward pickup and modern Paper detection.

## Configuration

```yaml
plugins:
  cmi:
    enable_integration_cmi: false
  cmilib:
    enable_integration_cmilib: true
```

CMI is used only for CMI-specific functionality. CMILib supplies action-bar and boss-bar
messages and does not require the CMI plugin.

## Compatibility

- Java 21.
- Paper 1.21.11 is the validated runtime.
- MobHunting 8.6.1 or newer.
- BagOfGold 4.5.6-JL.13 is the validated BagOfGold build at publication time.

CustomItemsLib, MobHunting and BagOfGold use independent semantic versions. Their compatible
versions are documented with each release.

## Validation

- Maven clean install completed successfully.
- Production startup with MySQL completed without CustomItemsLib, MobHunting or BagOfGold errors.
- SQLite testing covered reward payments, deposits, withdrawals and item pickup.
- CMILib 1.6.0.1 was validated without the CMI plugin installed.
