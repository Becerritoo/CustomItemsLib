# CustomItemsLib 1.3.0

CustomItemsLib 1.3.0 makes the shared library independent from its consumer
plugins while preserving existing reward items and stored data.

## Highlights

- Adds the optional `PhysicalCurrencyService` contract through Bukkit's `ServicesManager`.
- Removes build dependencies and class references to BagOfGold and MobHunting.
- Starts and exposes its commands without an economy or consumer plugin installed.
- Runs historical consumer-file imports once without deleting the source files.
- Prevents reward-block save iteration failures and bounded shutdown waits after worker failure.
- Reconciles reward accounting after bundle and merchant inventory operations settle.
- Retains CMILib as the maintained action-bar and boss-bar backend.
- Retires obsolete presentation adapters.

## Compatibility

- Java 21.
- Paper 1.21.11 is the validated runtime.
- BagOfGold 4.7.0 and MobHunting 8.7.0 are the validated consumer releases.

## Validation

- Standalone, BagOfGold-only, MobHunting-only and complete-stack startup and shutdown passed.
- The final build contains no references to BagOfGold or MobHunting implementation packages.
- Reward pickup, combination, nested portable money, Shopkeepers trades and persistence were tested in game.
