# CustomItemsLib 1.4.0

CustomItemsLib 1.4.0 adds the shared security and update infrastructure required
by the next maintained BagOfGold and MobHunting releases.

## Highlights

- Adds `SignedItemData` for consumer-owned item metadata that must not be treated as a reward or currency item.
- Exposes textured player heads without attaching reward metadata.
- Replaces the Spiget updater with a shared Hangar update service.
- Accepts only public, reviewed releases from the stable release channel for the server's exact Paper version.
- Validates the download filename, declared size and SHA-256 before staging a JAR for restart.
- Keeps the installed JAR filename when writing to Bukkit's update directory.

## Compatibility

- Java 21.
- Paper 1.21.11 is the current validation target.
- BagOfGold 4.8.0 and MobHunting 8.7.1 are the companion development releases.

## Validation

- All automated tests pass.
- Complete-stack startup passed on Paper 1.21.11 with BagOfGold, MobHunting and Shopkeepers.
- The three update commands handle unpublished Hangar projects without errors.
- Final in-game validation of signed Shopkeepers price templates is pending.
