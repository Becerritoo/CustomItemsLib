# CustomItemsLib 1.4.1

CustomItemsLib 1.4.1 hardens the token ledger used by physical-currency
consumers. A transaction that spends several signed items now claims every
token as one database operation.

## Highlights

- Claims all token UUIDs for a physical-currency operation in one transaction.
- Rolls back the complete batch when a duplicate or database failure is found.
- Rejects missing and repeated token identifiers before opening a connection.
- Uses one connection for the complete batch instead of one connection per item.
- Preserves the existing single-token API for compatible consumer plugins.

## Compatibility

- Java 21.
- Paper 1.21.11 is the current validation target.
- BagOfGold 4.8.1 is the companion physical-currency release.
- MobHunting 8.8.0 remains compatible.

## Validation

- Automated tests cover complete commits, full rollback on a database duplicate,
  and rejection of duplicate UUIDs before database access.
- Complete-stack startup and physical-currency spending passed on Paper 1.21.11.
- Runtime validation completed without duplicate-token or token-store errors.
